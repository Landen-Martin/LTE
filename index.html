What's new in v1.1

    
    
      
  • Syntax colours are back — now using a contenteditable editor so highlighting is baked right into the text. No more overlay drift, ever.
    • 
      
  • Richer token palette. Keywords, builtins, magic names like __name__, decorators, classes, functions, f-strings, operators, punctuation.
    • 
      
  • Dev mode. Settings tab with Vim keybindings, language selection, and an in-editor code runner.
    • 
      
  • Run code. Execute Python (via Pyodide), JavaScript, and HTML below the editor.
    • 
      
  • Vim mode. h j k l, w / b, 0 / $, gg / G, i a o O I A, x, dd, yy, p, u, :w.
    • 
      
  • Lined paper. Ruled, grid, and dotted styles with adjustable colour and a margin rule.
    • 
      
  • Bold, italic, underline. Toolbar buttons and Ctrl+B / I / U.
    •
