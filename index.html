What's new in v1.1

    
    
      
  • Dev mode. A new settings tab with Vim keybindings, language selection, and an in-editor code runner.
    • 
      
  • Run code. Execute Python (via Pyodide), JavaScript, and HTML directly in a split output panel below the editor.
    • 
      
  • Syntax highlighting. Colour-coded keywords, strings, numbers, comments, and functions for Python, JavaScript, HTML, CSS, C, JSON, and Markdown.
    • 
      
  • Vim mode. Normal-mode navigation with h j k l, w / b, 0 / $, gg / G, plus i a o O I A, x, dd, yy, p, u, and :w / :wq.
    • 
      
  • Lined paper. Ruled, grid, and dotted page styles with adjustable line colour and a margin rule.
    • 
      
  • Bold, italic, underline. Toolbar buttons and Ctrl+B / I / U shortcuts for the current selection.

Editor mode

          

            
            
          

          

            Normal mode: h j k l move · w / b word · 0 / $ line ends ·
            gg / G top / bottom · i a o O I A insert · x delete char ·
            dd delete line · yy yank · p paste · u undo ·
            : command mode (:w, :wq, :q, :set nu).
